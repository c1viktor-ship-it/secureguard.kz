# SecureGuard.kz — антикражное оборудование по всему Казахстану

Готовая адаптивная HTML-страница с развёрнутым описанием компании **SecureGuard.kz**, поставляющей решения для электронной защиты товаров магазинам в Казахстане.

## Что внутри

- `index.html` — полноценная публичная страница на русском языке: «О компании», ассортимент, RF/AM-технологии, отрасли торговли, работа по Казахстану и ответы на вопросы. Стили находятся внутри файла, поэтому дополнительной сборки и зависимостей не требуется.
- `ABOUT.md` — текстовая версия презентации компании для чтения на GitHub и повторного использования.
- `.nojekyll` — позволяет GitHub Pages публиковать файлы как обычный статический сайт.

## Как опубликовать на GitHub

1. Войдите на [github.com](https://github.com/) под своим аккаунтом.
2. Нажмите **+ → New repository** и назовите репозиторий `secureguard-kz`.
3. Отметьте **Public**. Нажмите **Create repository**.
4. Откройте созданный репозиторий, выберите **Add file → Upload files** и загрузите **файлы из архива**, а не ZIP как один файл. Нажмите **Commit changes**. Убедитесь, что `index.html` находится **в корне репозитория**.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Нажмите **Save**.
6. Когда GitHub Pages закончит публикацию, откройте `https://ВАШ-ЛОГИН.github.io/secureguard-kz/`.

> Для текущего подключённого аккаунта предполагаемый адрес после создания репозитория: `https://c1viktor-ship-it.github.io/secureguard-kz/`. Он **не работает до публикации**.

## Важно

Этот проект не меняет действующий сайт `secureguard.kz` и не подменяет его. Публикация на GitHub Pages создаст дополнительную публичную страницу. Утверждения о филиалах, гарантированном монтаже и сроках поставки в каждый город намеренно не добавлены. Перед публикацией желательно подтвердить актуальный перечень оборудования и условия продаж.
